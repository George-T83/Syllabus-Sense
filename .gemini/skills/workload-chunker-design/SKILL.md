# Workload & Bite-Sized Chunker Design

- Support 12 coursework types:
  1. 🚀 Final Project / Capstone
  2. 📝 Exam Study Plan
  3. ⚡ Quiz / Test Review
  4. 📚 Large Assignment / Lab Report
  5. 📄 Essay / Term Paper
  6. 🎤 Presentation / Slide Deck
  7. 📖 Textbook / Literature Reading
  8. 💻 Full-Stack Coding / Programming Project
  9. 🎨 Design Portfolio Showcase
  10. 👥 Group Project & Integration
  11. 🃏 Flashcard Spaced Repetition
  12. 🔬 Case Study Analysis Audit
- Support Retroactive Completion: past completed tasks remain on their original date; uncompleted tasks roll over dynamically.
- Provide dynamic relative workload badging (Light, Moderate, Heavy Peak) with manual date-shifting controls rather than arbitrary hour caps.
